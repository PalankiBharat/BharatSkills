# PR Body schema

## Required sections, in order

1. Summary (2-3 sentences)
2. Tech stack used (live-discovered, sourced) — table
3. Migration heatmap — see pr_body_heatmap_spec
4. Baseline parity evidence — row per suite × platform
5. Accepted deltas — table with sources
6. Reviewer checklist — tickable items
7. Files changed, by phase and source set
8. AI agent context — direct pointers to plans, research_notes, final review
9. Trail footer — single line

## Banned

- Unsourced technology claims (Rule 13 violation).
- Vague prose.
- Followup-style language ("TODO later").
- Any claim not backed by an artifact link.
