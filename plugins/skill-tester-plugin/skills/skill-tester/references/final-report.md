# Final QA Report Format

## Template

```markdown
# Skill QA Report: <skill-name>

**Date**: <YYYY-MM-DD HH:MM>
**Repo**: <repo-url>
**Version**: <start-version> → <end-version>
**Total iterations**: <n>
**Status**: PASS | PARTIAL | FAIL

## Validation Checklist

| # | Criterion | Source | Status |
|---|-----------|--------|--------|
| B01 | <rule> | SKILL.md:L20 | PASS |
| B02 | <rule> | references/naming.md | PASS |
| M01 | <rule> | hooks.json | PASS |

## Test Prompts

### 1. "<prompt text>" — PASS (iterations: <n>)
- Fixes applied: <list of changes>
- Final output quality: <1-line assessment>

### 2. "<prompt text>" — PASS (iterations: <n>)
- Fixes applied: <list>
- Final output quality: <assessment>

## Regression Check
- Re-ran prompt 1 after all fixes: PASS | FAIL
- Details: <if fail, what regressed>

## Versions Shipped
| Version | Commit | Summary |
|---------|--------|---------|
| v1.2.0 | abc123 | <one-line> |
| v1.2.1 | def456 | <one-line> |

## Issues Filed
- [#N](<url>) — <title> (if any unresolved)

## Recommendations
- <any remaining concerns or future improvements>

---
*Generated by skill-tester*
```

## Status definitions

- **PASS**: All behavioral and mechanical checks pass for all prompts,
  regression check passes
- **PARTIAL**: Most checks pass but some non-blocker items have
  known issues (GitHub issues filed)
- **FAIL**: Blocker-severity items remain unresolved after MAX_ITERATIONS
