# Session log

Each closing retro can write a one-paragraph entry here capturing what was investigated, which pitfalls matched, what was added to the skill, and the outcome. See `references/retro-questions.md` for the template.

Entries are named `YYYY-MM-DD-<short-slug>.md`.

The trail's purpose is pattern recognition across sessions, not full archival — keep each entry under 200 words. When a new session's symptom pattern-matches an old entry, the trail accelerates diagnosis.
